# E-CUP 2026 — Ценность пользователей поиска

Решение команды **Солодова С. М. и Чернышкова З. А.** для задачи «Ценность пользователей поиска» в рамках E-CUP 2026.

## Задача

Необходимо было предсказать **GMV каждого пользователя на следующие 30 дней** по истории его активности в поиске и каталоге.

Для решения задачи нужно было восстановить поведение пользователей по временным данным и определить, какие пользователи с наибольшей вероятностью совершат покупки и принесут GMV в будущем.

Основная метрика — **RMSLE**:

$$
\text{RMSLE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} \left( \log(1 + y_i) - \log(1 + \hat{y}_i) \right)^2}
$$

где $y_i$ — истинный GMV, $\hat{y}_i$ — предсказанный GMV, $n$ — число пользователей.

## Подход

В ходе работы:

* Провели **EDA** и изучили связь поисковой активности, корзины и покупок.
* Собрали признаки по временным окнам **7 / 14 / 30 / 60 / 90 дней**.
* Использовали данные о **поисках, добавлениях в корзину, заказах и GMV**.
* Добавили **recency и lifetime-признаки**, количество активных дней и интервалы между покупками.
* Рассчитали **конверсии, отношения между активностью и покупками, средний чек** и другие поведенческие признаки.
* Добавили признаки **динамики активности** — изменение показателей между разными временными окнами.
* Обучали модели на **`log1p(GMV)`** и оценивали качество с помощью **time-based Cross-Validation**.
* Протестировали **CatBoost и LightGBM**.
* Финальное решение построили на **ансамбле CatBoost + LightGBM**.
